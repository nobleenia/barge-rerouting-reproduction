# Barge Rerouting Reproduction

Methodological and behavioural reproduction of:

Cui, Y., Bilegan, I. C., Duchenne, E., and Duvivier, D.
"Demand rerouting mechanisms with revenue management for intermodal
barge transportation networks."

## Objectives

1. Construct the physical and time-space transportation networks.
2. Implement the DCA baseline.
3. Implement DCA-RM, DCA-Reroute, and DCA-RRM.
4. Reproduce the principal behavioural findings using documented synthetic data.
5. Model water-level-induced capacity changes and truck recourse.
6. Produce a transparent, tested, and reproducible technical-interview submission.

## Technology

- IBM CPLEX
- DOcplex
- NetworkX
- pandas
